# Support

This repository serves as the helpdesk for Distro users.

- **Report bugs:** Use the "🐞 Bug Report" issue template and include steps to reproduce plus logs/screenshots.
- **Request features / wishes:** Use the "✨ Feature Request / Wish" template and describe the use case and desired behavior.
- **Ask questions:** Use the "❓ Question" template if you are unsure whether behavior is expected.
- **Urgent issues:** Add a short impact statement (e.g., blocking, high, medium, low) so we can prioritize.

Before opening an issue:

- Search existing issues to reduce duplicates.
- Check the [Troubleshooting / FAQ](docs/TROUBLESHOOTING.md) for common installation and export problems.
- See the [Cubewise Distro product page](https://code.cubewise.com/software/innovation-labs/overview/) for the overview, downloads, and documentation.
